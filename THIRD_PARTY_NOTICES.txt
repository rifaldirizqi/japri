Japri: catatan lisensi komponen pihak ketiga
Japri: third-party notices

Kode Japri sendiri berlisensi MIT (lihat file LICENSE). Installer Windows dan image Docker Japri
juga berisi komponen pihak ketiga dengan lisensinya masing-masing:

- Japri.exe (launcher Windows) dibangun dengan Go dan berisi komponen yang teks lisensinya ada
  di bawah: runtime & standard library Go, golang.org/x/sys, github.com/jchv/go-webview2,
  github.com/jchv/go-winloader, dan WebView2Loader.dll (Microsoft).
- Paket npm di folder app\node_modules (atau /app/node_modules di image Docker). Teks lisensi
  tiap paket ada di folder paketnya masing-masing.
  Termasuk libsignal (dipakai Baileys buat enkripsi WhatsApp) yang berlisensi
  GNU General Public License v3.0 (GPL-3.0). Teks lisensinya ada di node_modules\libsignal\LICENSE,
  kode sumbernya ikut terpasang di folder yang sama, dan juga tersedia di
  https://github.com/WhiskeySockets/libsignal-node
- Node.js portable (folder node\, khusus installer Windows). Teks lisensinya ada di node\LICENSE.
